# QuickNotes

QuickNotes is a simple web application that allows users to create, categorize, search and delete notes. Notes are stored in the browser using localStorage, so they remain available after refreshing the page.

## Features

- Add notes
- Choose a note category
- Delete notes
- Search notes
- Validate notes
- Limit notes to 200 characters
- Display the total number of notes
- Save notes using localStorage
- Load notes after refreshing the page
- Responsive design for smaller screens
- Different visual styles for each category

## How to Run Locally

1. Clone the repository.
2. Open the `project1` folder.
3. Open `index.html` in a web browser.

No server or additional installation is required.
